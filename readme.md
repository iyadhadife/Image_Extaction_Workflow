# Data Extraction Workflow

## Objective

The objective of this project is to build an intelligent data extraction workflow that can process unstructured or semi-structured documents and populate structured outputs.

## Features

- **Schema-driven extraction**: Fill predefined fields according to a user-provided schema.
- **Autonomous field discovery**: Automatically identify and create relevant fields based on document content.

## Approach

Leveraging LLMs and advanced parsing techniques, the workflow ensures accurate, consistent, and adaptable extraction for diverse document types.
